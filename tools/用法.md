## 统一口径（先读这一段）

```
a_err 单位   : 12 位计数  (4096 counts = 360°,  11.38 counts/deg)
遥测 A 单位  : 10 位计数  (1024 counts = 360°,  2.84 counts/deg)
工具内部     : A × 4 还原成 12 位
⇒ 250 counts(12位) = 22°     62.6 counts(10位) = 22°

竖直 = A=787 (10位) = 3148 (12位)
下垂 = A=275 (10位) = 1100 (12位)      两者相差 512(10位) = 180.0°
状态列 T=5 表示电机使能中；只有 T=5 的帧参与统计
```

**改口径就必须改数字并注明。** 混用 10 位和 12 位会差 4 倍 —— 我们自己犯过（见 `05` 第 10 条）。

## 1. `swing_score.py` — 站了多久

```powershell
python swing_score.py <csv> [--tgt 787] [--zone 250]
```

| 输出项 | 含义 |
|---|---|
| `balance segments` | 满足 `\|a_err\| ≤ zone 且 ≥0.30 s 且 mean\|M\| ≥ 40` 的段 |
| `dur` | 该段时长 |
| `rod pp` | 该段摆杆峰峰值（度）—— **口径无关，最可靠** |
| `drift` | 大臂端点漂移（cnt/s） |
| `mean\|M\|` / `(x% sat)` | 电机平均占空比 / `\|M\|≥590` 的比例 |
| `pump time` | `E1` → 首次进入平衡段的耗时 |
| `best hold` | 最长一段 |
| `ARM FROZEN` | `\|dE\|<3 counts` 持续 >0.2 s 的窗口 —— **`M≠0` 时是手碰或绷线** |
| `VERDICT` | ≥10 s 实心捕获；3~10 s 短捕获；<3 s 只是碰到 |

**为什么要 `mean|M| ≥ 40` 这一条**：`M` 全程为 0 说明大臂被停住、杆是靠在什么东西上，
不是"控制住了"。这个过滤会打印 `[dropped]` 让你知道。

## 2. `phase_freq.py` — 站着的时候在做什么

```powershell
python phase_freq.py <csv> [--tgt 787] [--zone 250] [--seg 0]
```

`--seg N` 选第 N 长的平衡段（0 = 最长）。

| 输出项 | 含义 |
|---|---|
| `rod p-p` | 峰峰值（度） |
| `mean\|M\|` / `saturated` | 占空比 / 饱和率 —— **判断执行器有没有余量** |
| `zero-crossings` / `DFT peak` | 振荡频率的两种估法 |
| **`lag scan`** | `corr(M, θ(t−lag))` 的扫描表 |

**怎么读 `lag scan`**（这是本工具的核心）：

```
lag = 0 ms          -> M 与【角度】同相  = 刚度/弹簧行为
lag ≈ 1/4 周期      -> M 与【角速度】同相 = 阻尼行为
                     6.5 Hz 时 1/4 周期 ≈ 38 ms，所以看 lag=+30~+40 ms
```

- `corr` 在 lag≈0 最大 ⇒ 指令主要是**刚度**，几乎没有阻尼
- `corr` 在 lag≈+38 ms 最大 ⇒ 指令主要是**阻尼**（正常 PD 应该偏这边）
- 两个峰值差不多 ⇒ P 和 D 各占一半

**例**（`v42_r1`）：lag=−10 处 0.826，lag=0 处 0.808，lag=+30 处 0.022
⇒ **纯刚度，阻尼贡献接近零。**

## 3. `dump_window.py` — 逐帧看

```powershell
python dump_window.py <csv> <t0> <t1> [--tgt 787]
```

| 输出项 | 含义 |
|---|---|
| `err[deg]` | 距竖直的带符号最短角，`0`=竖直，`±180`=下垂 |
| `rate[deg/s]` | 已**解绕**的后向差分 |
| `~` 标记 | 该样本跨了 ±180° 接缝，速率只作参考 |
| `M` | 电机命令 |

**为什么必须解绕**：`a_err` 在 ±180°（下垂点）绕回。直接差分会得到 2000~3200 °/s 的假尖峰。
**这个伪影害我们误判过一次**（见 `05` 第 9 条）。

**典型用途**：看交接前后 0.5 s 到底发生了什么
```powershell
python dump_window.py "..\07_原始数据\v53_r3.csv" 42.90 43.30
```
