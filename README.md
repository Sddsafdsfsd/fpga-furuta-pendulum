# FPGA 倒立摆自平衡姿态控制系统

纯 FPGA 硬件逻辑实现的旋转倒立摆（Furuta Pendulum）控制器：**从下垂静止自动起摆**，
把摆杆送到竖直并转入闭环平衡。

无处理器、无软件调度——滤波、姿态解算、能量泵能、四阶 PD、状态机全部在硬件逻辑内完成。

---

## 关键指标

| 项目 | 指标 |
|---|---|
| 连续平衡时间 | 实测 > 190 s |
| 稳态摆幅 | ≤ ±11° |
| 自动起摆成功率 | 100%（从下垂静止开始） |
| 角度更新周期 | 4.1 ms（244 Hz） |

| 遥测 | 27 字节 ASCII，115200 8N1，100 Hz |
| 逻辑资源 | 约 2.2k LU，4.5 个 DSP |

## 控制方案

### 1. 归一化机械能

以下垂静止为 0、竖直静止为 2.0（Q12 定点 8192）：

```
ε = J/(2mgl)·ω² + (1 + cos θ)
```

由实测摆动周期 `T = 0.512 s` 反标定 `J/(mgl) = (T/2π)²`，
使控制参数与具体质量、尺寸解耦。

### 2. 起摆：能量反馈的比例幅值泵能

```
M = k·(ε_target − ε) − ½·E_arm
```

驱动幅值正比于"还差多少能量"，能量接近目标时幅值自然衰减，
摆杆以接近零的相对速度抵达竖直，平衡律可平稳接管。

**相比之下，定幅方波泵能只能以固定能量量子逐周期累加，必然过冲**——
这是本方案与常规做法的核心差别。

### 3. 平衡：四阶整数 PD（无积分器）

```
u = KP_a·e_θ + KD_a·θ̇ + KP_e·e_arm + KD_e·ė_arm
```

刻意不含积分项：
- 摆杆角是周期量（模 4096），积分会跨圈累计出与真实误差无关的偏移；
- 臂位置积分会在摆杆掉落的瞬间持续输出，与起摆逻辑争夺执行机构。

### 4. 执行机构行程管理

驱动臂行程是欠驱动系统的硬约束：

- **软限位**：`|臂| > 150 cnt` 起衰减 PD 输出，`≥ 400 cnt` 施加反向偏置
- **迟滞回中**：`> 480 cnt` 置位、`< 380 cnt` 复位，置位期间叠加 ±560 强回中
- **硬保护**：`|臂| > 380 cnt` 时输出被强制反向，防止机构越程

## 重要工程结论

1. **泵能的有效作用窗口不得小于半个摆动周期。**
   若只在摆杆处于某个角度扇区时才允许出力（例如要求 `|θ| > 90°`），
   每周期中可用于加速的时间不足一半，逐周期净增能量落到阈值以下，
   表现为"甩而不升"——振幅停滞在某个角度再也上不去。

2. **能量评价必须用轨迹的不变量，不能用瞬时量替代。**
   归一化能量在无外力矩时沿轨迹守恒，是泵能唯一正确的控制量。

3. **有符号运算要做显式符号扩展。**
   Verilog 中只要表达式含一个无符号操作数，整体就按无符号解释，
   `-4096` 会被当成 `+4096`——曾导致"电机完全不出力"的故障。

## 构建

需要 Gowin EDA（V1.9.11.03 及以上）。

```powershell
tools\build_pd.ps1 -Stage 5 -OutName f1_balance.fs -I2cDiv 1000
```

器件：`GW1N-UV9EQ144C6/I5`（Gowin Programmer 识别为 `GW1N-9C`，ID `0x1100481B`）。
输出 `.fs` 应为 2,070,604 字节。

## 烧录

```powershell
tools\program_f1.ps1 -Mode flash -Fs f1_balance.fs
```

烧录后核对 `User Code`（本仓库源码对应 **`0xECBD`**）。

## 采集

```powershell
tools\read_serial.ps1 -Seconds 60 -Live -Send "E1" -SendGapMs 90000 -Save run.csv
```

## 遥测协议

上行 27 字节定长 ASCII：

```
A#### T#### E±#### M±####
```

| 字段 | 含义 | 说明 |
|---|---|---|
| `A` | 摆杆角度 | 10 位，2.84 cnt/°，竖直向上约 787，自然下垂约 275 |
| `T` | 状态 | `T=5` 表示电机使能 |
| `E` | 驱动臂位置 | 4096 cnt/圈，带符号 |
| `M` | 电机指令 | 限幅 ±600 |

下行指令：

| 指令 | 功能 |
|---|---|
| `E1` / `E0` | 使能 / 停止电机 |
| `Z` | 把当前角度捕获为平衡目标点（带合理性窗口，越界丢弃） |
| `P<n>` | 开环占空比测试，2 秒看门狗自动停 |
